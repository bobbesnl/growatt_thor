# Growatt THOR EV Charger

Local OCPP 1.6 integration for Growatt THOR EV chargers.

## Features

- Real-time monitoring (power, current, voltage, energy)
- Load balancing with configurable grid limits
- Manual charging control (start/stop buttons)
- Charging schedules
- Session history tracking
- No cloud dependency
- and much more...

## Installation

Add via HACS custom repository or install manually.

[Full documentation](https://github.com/bobbesnl/growatt_thor)
